**SceneManager.tsx** — Visibility-toggle scene manager:
- `'use client'` directive
- Import `useRef` from react, `useFrame` from R3F, `THREE` from three
- Import `useScrollProgress` and `getChapterIndex` from existing modules
- Create a `groupRefs` via `useRef<(THREE.Group | null)[]>([])` — one ref per chapter
- In `useFrame`, read `progressRef.current`, compute chapter index via `getChapterIndex`, set `group.visible = (i === chapterIdx)` for each group ref
- Render 6 `<group>` elements with ref callbacks: `ref={(el) => { groupRefs.current[i] = el; }}`
- Each group gets a `key` and is positioned at the scene's focal center (matching the lookAt from chapters.ts waypoints):
  - Group 0: position=[0, 0, 0]
  - Group 1: position=[1, 0, -5]
  - Group 2: position=[-1, 0, -11]
  - Group 3: position=[0, 0, -17]
  - Group 4: position=[0, 0, -23]
  - Group 5: position=[0, 0, -29]
- Inside each group, render a placeholder `<mesh>` (small box or sphere) so the scenes are visually distinguishable during development. These placeholders will be replaced with actual scene components in Plan 02. Use different colors per group for easy identification.
- CRITICAL: Do NOT use conditional rendering (`{idx === 0 && <Scene />}`). All groups are always mounted. Only `visible` toggles.

**ParticleField.tsx** — Ambient particle system:
- `'use client'` directive
- `PARTICLE_COUNT = 2000` constant at module level
- Generate positions via `useMemo(() => { ... }, [])` — Float32Array of PARTICLE_COUNT * 3 values
- Distribution volume: x: (-15, 15), y: (-5, 5), z: (5, -35) — covers the full camera path from chapter 0 (z=5) to chapter 5 (z=-29)
- Use `useFrame` to apply very gentle rotation: `pointsRef.current.rotation.y = elapsedTime * 0.003`
- Render `<points>` with `<bufferGeometry>` + `<bufferAttribute attach="attributes-position">` and `<pointsMaterial size={0.02} color="#6666cc" sizeAttenuation transparent opacity={0.4} depthWrite={false} />`
- This component lives OUTSIDE SceneManager — always visible regardless of chapter

**TexturePlane.tsx** — Reusable texture plane:
- `'use client'` directive
- Props interface: `{ url: string; width?: number; height?: number; position?: [number, number, number]; rotation?: [number, number, number] }`
- Defaults: width=3.2, height=2 (16:10 aspect), position=[0,0,0], rotation=[0,0,0]
- Use `useTexture(url)` from drei to load texture
- Render `<mesh>` with `<planeGeometry args={[width, height]}>` and `<meshBasicMaterial map={texture} transparent />`
- meshBasicMaterial is unlit — correct for portfolio image display

All three components must pass TypeScript strict checks. No `any` types.
