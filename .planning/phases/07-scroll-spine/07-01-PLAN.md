```
project-3:  position(3, 3, -6)   lookAt(0, 1, -8)
project-4:  position(-3, 1.5, -10) lookAt(-3, 0, -13)
project-5:  position(0, 2, -15)  lookAt(0, 0, -18)
```

Export derived constants:
- `CHAPTER_COUNT = CHAPTERS.length` (always 6, derived — never hardcoded)
- `CHAPTER_STEP = 1 / CHAPTER_COUNT`
- `getChapterIndex(progress: number): number` — `Math.min(Math.floor(progress * CHAPTER_COUNT), CHAPTER_COUNT - 1)`
- `getChapterProgress(progress: number): number` — local 0-1 within current chapter

**CRITICAL:** No magic number `6` anywhere in this file or any file that imports from it. Everything derives from `CHAPTERS.length`.

**Step 3: Create `src/components/lab2/hooks/useScrollProgress.ts`**

`'use client'` directive. Export `useScrollProgress()` hook that:
1. Creates `progressRef = useRef(0)`
2. Calls `useLenis(({ progress }) => { progressRef.current = progress; })` — uses Lenis's built-in animated progress (0-1), NOT raw scrollY
3. Returns `progressRef` (MutableRefObject<number>)

This follows STATE.md decision: "애니메이션 값은 useRef" — no useState for animation values.

**Step 4: Create `src/components/lab2/ui/LenisProvider.tsx`**

`'use client'` directive. Default export `LenisProvider({ children })` that:
1. Creates `lenisRef = useRef<LenisRef>(null)`
2. In `useEffect`, calls `addEffect((t) => { lenisRef.current?.lenis?.raf(t); })` to drive Lenis from R3F's RAF loop (single RAF, no dual-loop jank)
3. Stores cleanup return from `addEffect` and returns it from useEffect
4. Renders `<ReactLenis ref={lenisRef} root options={{ autoRaf: false, lerp: 0.08, duration: 1.2 }}>{children}</ReactLenis>`

**Import note:** Import `ReactLenis` and type `LenisRef` from `'lenis/react'`. Import `addEffect` from `'@react-three/fiber'`.

**CRITICAL:** `autoRaf: false` is mandatory — Lenis must NOT run its own RAF when R3F drives it via `addEffect`. Dual RAF causes 40fps drops (see research pitfall 1).

**Also import Lenis CSS:** Add `import 'lenis/dist/lenis.css'` at the top of LenisProvider (see research pitfall 4 — missing CSS causes layout issues).
